Code Formatter は、生のコードファイルを Chrome で読みやすく表示します。タブに .json、.css、.js ファイルや JSON を返す API が表示されると、タブを開いた時点で自動的に整形します。通常のウェブサイトを変更することはありません。

JSON、CSS、JavaScript はきれいにインデントされます。その他の多くの一般的な言語には、シンタックスの色分けが付きます。

JSON では次のことができます。
- オブジェクトや配列ごとに、それぞれの矢印で折りたためます
- すべて、または現在のブロックだけを、キーボードショートカットで折りたたみ・展開できます
- 値をクリックすると、そのパス（例: $.data[3].email）を確認してコピーできます
- リンクはクリックで開け、長い数値も正確に保たれます

「整形済み」と「元のコード」を切り替えたり、コードをコピー・ダウンロードしたり、行番号や折り返しをオンにしたりできます。外観は「自動」「ライト」「ダーク」から選べ、「自動」はデバイスの設定に従います。テーマは 23 種類から選べます。

パソコン上のファイルを整形するには、chrome://extensions を開き、Code Formatter の「詳細」をクリックして、「ファイルの URL へのアクセスを許可する」をオンにしてください。

Code Formatter はブラウザ内でオフラインで動作する、無料のオープンソースです。アカウント登録、トラッキング、データ収集はありません。

Code Formatter は、スポンサーである Crustat への小さなリンクを 1 つ、「スポンサー」というラベル付きで表示します。表示場所は、ビューアー下部のバー、ポップアップ、ウェルカムページです。これは通常のリンクで、何も読み込まず、データも収集しません。クリックしない限り、何も送信されません。
