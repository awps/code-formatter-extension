TITLE
Відкрийте файл із кодом. Він форматується сам. Code Formatter #Shorts

DESCRIPTION
Відкрийте сирий файл із кодом у Chrome, і Code Formatter зробить його читабельним, щойно відкриється вкладка. Згортайте об'єкти JSON, копіюйте шлях будь-якого значення, перемикайтеся між відформатованим і оригінальним текстом і користуйтеся світлою чи темною темою вашого пристрою. Усе працює у вашому браузері.
