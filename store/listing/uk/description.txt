Code Formatter робить сирі файли коду зручними для читання в Chrome. Коли вкладка показує файл .json, .css чи .js або API, що повертає JSON, розширення форматує його одразу після відкриття вкладки. Звичайні вебсайти воно ніколи не змінює.

JSON, CSS і JavaScript отримують акуратні відступи. Багато інших поширених мов отримують підсвічування синтаксису.

Для JSON:
- Згортайте будь-який об’єкт чи масив його власною стрілкою
- Згортайте або розгортайте все чи лише поточний блок клавіатурними скороченнями
- Натисніть значення, щоб побачити й скопіювати його шлях, наприклад $.data[3].email
- Відкривайте посилання одним натисканням; довгі числа зберігаються точно

Перемикайтеся між «Відформатовано» та «Оригінал», копіюйте чи завантажуйте код, вмикайте номери рядків або перенесення слів. Вигляд може бути Авто, Світлий або Темний; Авто підлаштовується під ваш пристрій. На вибір є 23 теми.

Для локальних файлів відкрийте chrome://extensions, натисніть «Докладніше» біля Code Formatter і ввімкніть «Дозволити доступ до URL-адрес файлів».

Code Formatter працює офлайн у вашому браузері, безкоштовний і з відкритим кодом, без облікового запису, стеження чи збору даних.

Code Formatter показує одне невелике посилання на нашого спонсора Crustat з позначкою «Спонсоровано»: у нижній панелі переглядача, у спливаючому вікні та на сторінці привітання. Це звичайне посилання: воно нічого не завантажує, не збирає даних і нічого не надсилає, доки ви на нього не натиснете.
