Code Formatter 让原始代码文件在 Chrome 中清晰易读。当标签页显示 .json、.css 或 .js 文件，或返回 JSON 的 API 时，它会在标签页打开时自动格式化。它从不修改普通网站。

JSON、CSS 和 JavaScript 会重新整理缩进。其他许多常见语言则提供语法着色。

JSON 功能：
- 每个对象或数组都可以用各自的箭头折叠
- 使用键盘快捷键全部折叠、全部展开，或只折叠、展开当前块
- 点击某个值即可查看并复制它的路径，例如 $.data[3].email
- 点击链接即可打开，长数字保持精确

你可以在“已格式化”和“原始”之间切换，复制或下载代码，并开启行号或自动换行。外观可设为自动、浅色或深色，“自动”会跟随你的设备。共有 23 个主题可选。

要格式化本地文件，请打开 chrome://extensions，点击 Code Formatter 的“详细信息”，然后开启“允许访问文件网址”。

Code Formatter 在浏览器中离线运行，免费且开源，无需账号，没有跟踪，也不收集任何数据。

Code Formatter 会显示一个指向赞助商 Crustat 的小链接，并标注“赞助”，位置在查看器底部栏、弹出窗口和欢迎页面。它只是一个普通链接：不加载任何内容，不收集数据，除非你点击，否则不会发送任何信息。
