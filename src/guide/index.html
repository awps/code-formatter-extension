Code Formatter

Open a code file. It formats itself.

Code Formatter works on its own. There are no buttons to press and nothing to select: open a code file in a browser tab and it is formatted automatically.

Open a JSON example Open a CSS example

How it works

  1. example.com/app.min.css
    .json.css.js.ts.xml.yaml

    1Open a code file in a tab

    Click a link that ends in .json, .css, .js, .ts, .xml, .yaml…, open an API URL that returns JSON, or drag a file from your computer into Chrome.

  2. .btn{color:#fff;padding:4px 8px}.btn:hover{opacity:.8}
    .btn {
    color: #fff;
    padding: 4px 8px;
    }

    2It is formatted right away

    Minified JSON, CSS and JavaScript are re-indented. Every file gets syntax highlighting, line numbers and arrows to collapse blocks.

    3Use the toolbars

    At the top: switch between formatted and original, copy, download, and open the settings for theme, line numbers and word wrap. At the bottom: collapse or expand everything.

Open links

Links inside the data are underlined. Hold Ctrl (⌘ on Mac) and click to open them.

Search

Press Ctrl+F (⌘+F on Mac) to search inside the file.

Good to know

It only works on pages that show a raw file. It does not change code shown inside normal websites, forums or online editors.

Settings you change in the toolbar or in the extension popup are remembered for all files.

Everything runs on your computer. Your code is never sent anywhere.
